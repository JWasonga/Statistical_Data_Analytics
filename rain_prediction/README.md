# Rain Prediction in Australia 

A machine learning project that predicts whether it will rain tomorrow at various Australian weather stations using binary classification. 

## Problem Statement
Given today's weather measurements (such as temperature, humidity, wind speed, and atmospheric pressure) from a specific Australian weather station, the goal is to predict the binary target variable `RainTomorrow` (Will it rain tomorrow? Yes/No).

## Dataset
* **Source:** Rain in Australia — Kaggle / Bureau of Meteorology
* **Samples:** ~145,460 daily station records across 49 stations (2007–2017).
* **Data Cleaning Note:** High-missingness features (`Evaporation`, `Sunshine`, `Cloud9am`, `Cloud3pm`) containing >30% null values were dropped upon load. Rows containing missing targets were also removed, leaving a final clean dataset of **~142,000 rows**.

### Feature Glossary

| Feature | Description |
| :--- | :--- |
| **Date / Location** | Observation date and specific weather station location |
| **MinTemp / MaxTemp** | Minimum and maximum daily temperature (°C) |
| **Rainfall** | Daily total rainfall measurement (mm) |
| **WindGustDir / WindGustSpeed** | Strongest wind gust direction and speed (km/h) |
| **WindDir9am / WindDir3pm** | Wind direction recorded at 9:00 AM and 3:00 PM |
| **WindSpeed9am / WindSpeed3pm**| Wind speed (km/h) recorded at 9:00 AM and 3:00 PM |
| **Humidity9am / Humidity3pm** | Relative humidity percentage recorded at 9:00 AM and 3:00 PM |
| **Pressure9am / Pressure3pm** | Atmospheric pressure (hPa) recorded at 9:00 AM and 3:00 PM |
| **Temp9am / Temp3pm** | Ambient temperature (°C) recorded at 9:00 AM and 3:00 PM |
| **RainToday** | Boolean indicator ('Yes'/'No') if rainfall exceeded 1mm today |
| **RainTomorrow** | **Target variable** (0 = No Rain, 1 = Rain) |

## Results & Model Evaluation
The dataset exhibits a mild class imbalance (~78% no-rain days vs. ~22% rain days). Because a baseline model predicting "No Rain" yields an automatic 78% accuracy, **F1-Score** on the positive (Rain) class was used as our primary evaluation metric. 

Eight classification variants were evaluated on the test set, ranked by F1-Score:

| Model | Accuracy | Precision | Recall | F1 Score |
| :--- | :---: | :---: | :---: | :---: |
| **Random Forest** | 0.8555 | 0.7789 | 0.4962 | **0.6062** |
| **Random Forest (Tuned)** | 0.8545 | 0.7744 | 0.4954 | **0.6042** |
| **Gradient Boosting** | 0.8506 | 0.7560 | 0.4927 | **0.5966** |
| **Logistic Regression** | 0.8468 | 0.7332 | 0.4976 | **0.5928** |
| **Decision Tree** | 0.8386 | 0.7039 | 0.4836 | **0.5733** |
| **Naive Bayes** | 0.6544 | 0.3637 | 0.7230 | **0.4840** |
| **KNN (k=3)** | 0.8069 | 0.6139 | 0.3736 | **0.4646** |
| **Linear SVM** | 0.5540 | 0.2740 | 0.5997 | **0.3761** |

* **Hyperparameter Tuning:** Grid search optimization yielded the following optimal parameters for Random Forest: `{'max_depth': None, 'min_samples_split': 5, 'n_estimators': 200}` (Cross-Validation F1 = 0.597).

## Key Insights & Findings
* **The Afternoon Signal:** `Humidity3pm` proved to be the single strongest predictor of rain (correlation ≈ 0.45). Afternoon humidity levels offer a much clearer forecasting signal than morning readings. 
* **Pressure Dynamics:** Lower 3:00 PM atmospheric pressure correlates highly with rain probability. An engineered feature, `PressureChange` (3:00 PM − 9:00 AM), further refined this signal.
* **Rain Breeds Rain:** `RainToday` is a strong leading indicator. If it rains today, the likelihood of rain tomorrow spikes from ~17% to ~46%. However, it is not entirely deterministic on its own.
* **Algorithm Synergy:** Tree ensembles (Random Forest and Gradient Boosting) dominated the leaderboard. They inherently handled the dense combination of continuous scales and one-hot encoded geographic/wind indicators better than distance or linear models.
* **Trade-offs (Naive Bayes & SVM):** Naive Bayes sacrificed massive precision to achieve our highest recall (0.72), making it a candidate if the penalty for missing a rain event is catastrophic (e.g., flash flood or farm management). Linear SVM performed poorly and scaled incredibly slowly due to the computation weight of 142k rows against high-cardinality geographic features.
